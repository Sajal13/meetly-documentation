# Definition of Done

A feature is complete only when applicable items below are satisfied:

- Requirement documented.
- User flow documented.
- Database design updated.
- Migration created.
- DTO created.
- Validation implemented.
- Service/use case implemented.
- Controller/API implemented.
- Authorization implemented.
- API documentation updated.
- Unit tests written.
- Integration tests written where needed.
- Error cases handled.
- Logging implemented where needed.
- Audit logging implemented where required.
- Frontend integration completed.
- Documentation updated.
- Code reviewed.
- Production considerations checked.

## Additional ticketing/payment gates
- Concurrency behavior tested.
- Idempotency behavior tested.
- Retry behavior tested.
- Refund/cancellation behavior tested.
- Webhook signature verification tested.
- No client-supplied price/total/inventory/payment state is trusted.
