# Personas & User Stories

## User stories

### Discovery
- As a guest, I want to browse public events so that I can discover events without logging in.
- As a user, I want to search events so that I can find relevant events quickly.
- As a user, I want to filter events by category, location, date, and price.
- As a user, I want to view event details and exact location information.

### Authentication
- As a user, I want to request an OTP to sign up or log in.
- As a user, I want OTP verification to be secure and one-time.
- As an admin, I want email/password authentication.
- As an admin, I want MFA before accessing administration features.

### Ticketing
- As a user, I want to select ticket types and quantities.
- As a user, I want temporary reservation during checkout.
- As a user, I want to pay for an order.
- As a user, I want to receive a generated ticket and QR code after successful payment.
- As an admin, I want to check tickets in.

### Events
- As a user, I want to submit an event request.
- As an admin, I want to approve/reject event requests.
- As an admin, I want to create, edit, publish, unpublish, cancel, and duplicate events.

### Account
- As a user, I want to view orders and tickets.
- As a user, I want to manage my profile.
- As a user, I want to favorite events.
- As a user, I want to review events I attended.
- As a user, I want notifications for important event/order/payment changes.

### Administration
- As an admin, I want user management.
- As an admin, I want category and organizer management.
- As a super admin, I want administrator, role, and permission management.
- As an admin, I want analytics and audit logs.
